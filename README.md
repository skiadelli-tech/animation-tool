# 🎬 Δημιουργός Κινούμενων Εικόνων

Μια εφαρμογή για παιδιά του Δημοτικού. Με αυτήν φτιάχνουν μικρές κινούμενες εικόνες (animation) καρέ καρέ και τις αποθηκεύουν ως αρχείο GIF.

Δημιουργός: Μαρία Σκιαδέλλη

## Τι μπορούν να κάνουν τα παιδιά

- Να ζωγραφίσουν ελεύθερα, να σβήσουν με τη γόμα, να γράψουν κείμενο και να προσθέσουν συννεφάκια ομιλίας, σκέψης ή κραυγής.
- Να βάλουν αυτοκόλλητα (emoji ή εικόνες από τη βιβλιοθήκη του Δημιουργού Comics) και δικές τους εικόνες.
- Να διαλέξουν φόντο για ένα καρέ ή για όλα μαζί.
- Να φτιάξουν τα καρέ της κίνησης: με το «⧉ Αντίγραφο καρέ» δημιουργούν ένα νέο καρέ ίδιο με το προηγούμενο και μετακινούν λίγο τα αντικείμενα. Το προηγούμενο καρέ φαίνεται αχνά από πίσω (onion skin), για να βλέπουν πόσο μετακίνησαν κάτι.
- Να αλλάξουν τη σειρά των καρέ, την ταχύτητα της κίνησης και τη διάρκεια κάθε καρέ.
- Να δουν την κινούμενη εικόνα και να την αποθηκεύσουν ως αρχείο GIF, που ανοίγει σε κάθε υπολογιστή και κινητό.
- Να αποθηκεύσουν το έργο τους σε αρχείο (.json) και να συνεχίσουν αργότερα.

## Πώς ανοίγει

Αρκεί να ανοίξει το `AnimationCreator_GR_v1.html` σε έναν browser (Chrome, Edge, Firefox). Δεν χρειάζεται εγκατάσταση ούτε σύνδεση στο διαδίκτυο, γιατί όλα όσα χρειάζεται η εφαρμογή είναι μέσα στο αρχείο. Τα έργα των παιδιών δεν στέλνονται πουθενά: μένουν στον υπολογιστή, στον φάκελο Λήψεις.

## Οι εικόνες της βιβλιοθήκης

Τα αυτοκόλλητα-εικόνες βρίσκονται στο αρχείο `stickers-library.js`, το ίδιο που χρησιμοποιεί και ο [Δημιουργός Comics](https://github.com/skiadelli-tech). Η εφαρμογή το βρίσκει σε μία από αυτές τις θέσεις:

1. στον ίδιο φάκελο με την εφαρμογή, όπως σε αυτό το repository
2. στον διπλανό φάκελο `comics tool` (`../comics tool/stickers-library.js`), αν οι δύο εφαρμογές βρίσκονται σε φακέλους δίπλα δίπλα

Αν η εφαρμογή δεν βρει το αρχείο, λείπουν μόνο αυτές οι εικόνες. Τα emoji και όλα τα υπόλοιπα δουλεύουν κανονικά.
